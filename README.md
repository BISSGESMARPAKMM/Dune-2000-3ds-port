# Dune-2000-3ds-port
This is a port of dune 2000 for the new 3ds. Hasn't been tested on original 3ds. All you do is un-zip the file and drop it under D:/3ds/(place file here). on the 3ds you need to go into the homebrew menu and go into Dune2000 then run the .3dsx file. this is currently in early development and doesn't have any gameplay.
